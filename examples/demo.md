## 先讲个直觉

想象你被蒙住眼睛丢在山上，任务是走到山谷最低点。

你看不见全局地形，但脚能感觉到**哪个方向最陡**。于是策略很简单：每次都朝最陡的下坡方向迈一小步，然后重新感受一次坡度，再迈下一步。

梯度下降干的就是这件事。「最陡的方向」在数学上叫**梯度**，「一小步」叫**学习率**。

## 核心公式

设损失函数为 $J(\theta)$，参数更新规则是：

$$
\theta_{t+1} = \theta_t - \alpha \nabla J(\theta_t)
$$

其中 $\alpha$ 是学习率，$\nabla J(\theta_t)$ 是当前点的梯度。

注意那个**减号**，它是整个算法的灵魂：梯度指向函数上升最快的方向，我们要下山，所以往反方向走。

---

## 学习率怎么选

学习率 $\alpha$ 是最需要调的超参数，三种典型情况：

1. **太小**：每步挪一厘米，跑一整晚还在山腰
2. **太大**：一步迈过山谷，弹到对面山坡，损失值反而越来越大
3. **刚好**：几十步稳稳收敛

经验起点是 $\alpha = 0.01$，然后按 3 倍上下试探。如果 loss 曲线出现剧烈震荡，先把学习率砍一半。

> 调参口诀：loss 不降就减小学习率，loss 震荡也减小学习率，loss 降得太慢才考虑加大。

## 三种变体的取舍

| 变体 | 每步用多少样本 | 特点 |
| --- | --- | --- |
| 批量 BGD | 全部 | 方向准，但一步要算全量数据，慢 |
| 随机 SGD | 1 个 | 快，但方向抖，容易在最优点附近打转 |
| 小批量 MBGD | 32～256 | 实际工程里的默认选择 |

## 十行代码写一个

```python
import numpy as np

def gradient_descent(grad_fn, theta, lr=0.01, steps=1000, tol=1e-6):
    for i in range(steps):
        g = grad_fn(theta)
        theta_new = theta - lr * g
        if np.linalg.norm(theta_new - theta) < tol:
            print(f"第 {i} 步收敛")
            break
        theta = theta_new
    return theta
```

## 一句话总结

梯度下降 = 沿着最陡的反方向、迈着合适大小的步子、反复走，直到走不动为止。

理解了这个，后面的 Momentum、AdaGrad、Adam 都只是在回答两个问题：**方向要不要修正**，**步子要不要自适应**。
